# FitCore – Fitness Landing Page

A modern, responsive landing page for a fitness coaching brand.
Designed to showcase services, build trust, and convert visitors into clients.

#  Tech Stack

* HTML5
* Tailwind CSS
* JavaScript (ES6)

# ✨ Features

* Responsive design (mobile-first)
* Clean and modern UI
* Hero section with CTA
* Services section
* Testimonials section
* Contact section
* Fast loading performance
